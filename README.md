# 夸克网盘批量转存助手（油猴脚本）

突破夸克网盘单次转存的文件数量限制：自动扫描分享链接的完整目录结构，按 **每批 ≤ 300 个文件** 智能分批转存，保留原目录结构，失败批次可一键重试或拆半重试。

**核心能力：扫描 → 自动去重比对 → 分批 → 转存 → 汇总 → 失败重试**，已转存的文件自动跳过，不重复转存。

## 背景

- 夸克网盘限制一次性转存的文件数量，大分享只能手动拆分多次转存
- 手动拆分繁琐，且容易漏掉文件
- 中断后续传容易重复转存已保存的文件
- 本脚本全自动完成：扫描 → 去重 → 分批 → 转存 → 汇总 → 失败重试

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展
2. 点击仓库中的 `quark-batch-save.user.js` → Raw 按钮
3. Tampermonkey 会弹出安装页，确认安装；或手动新建脚本粘贴全文保存

## 使用

1. 浏览器登录夸克网盘网页版
2. 打开分享链接 `https://pan.quark.cn/s/xxxx`
3. 页面右上角出现「夸克批量转存助手」面板：
   - **授权**：脚本会自动获取访问权限（从页面内存 / URL 参数 / 输入框自动提取提取码，无码分享直接授权）；自动授权失败时再手动填提取码点「授权」
   - 点「① 扫描目录结构」：递归扫描全部文件和文件夹，显示统计
   - **目标路径**：可直接输入路径（如 `/转存合集`），也可点「浏览」按钮在弹出的网盘目录树中点选目标文件夹（支持进入子目录、面包屑跳转、新建文件夹）
   - **每批数量**：默认 300，上限 500
   - **比对去重**：默认开启，转存前与目标网盘已有内容逐级比对，跳过已存在的文件/文件夹（关闭则全量转存）
   - 点「② 开始转存」：逐批转存，实时显示每批状态（待转存/转存中/成功/失败）
4. 失败处理：
   - 单批失败 → 对应行点「重试」原样重跑（重试时也会去重，已转存的自动跳过）
   - 反复失败 → 点「拆半」把该批一分为二再转存（拆半后的批次也带「重试」按钮）
   - 「重试未完成」一键重跑所有未成功批次（pending + failed）
5. 「导出结构JSON」可下载完整目录树 + 各批次结果存档，用于核对是否有遗漏

## 去重比对规则

转存前自动与目标网盘已有内容逐级比对，规则如下：

| 分享侧条目 | 目标侧同名条目 | 处理方式 |
|---|---|---|
| 文件 | 文件（同名） | 跳过，不转存 |
| 文件 | 文件夹 / 不存在 | 转存该文件 |
| 文件夹 | 文件夹（同名） | 进入下一级继续比对，只转存缺失部分 |
| 文件夹 | 文件 / 不存在 | 整个文件夹转存 |

- 对目标侧已存在的同名文件夹，脚本会强制下钻到子级比对，避免夸克 `save` 接口整体转存文件夹导致重复
- 失败批次重试时同样执行去重，防止部分已转存的文件被重复转存
- 去重可通过面板开关关闭

## 特性

- 递归扫描分享目录树（BFS，全量分页，不漏文件）
- 贪心分批：同目录文件装箱成批；单文件夹超限时自动下钻到子目录拆分
- **自动去重**：转存前与目标网盘逐级比对，跳过已存在文件/文件夹；重试时同样去重
- **目录浏览器**：目标路径支持点选，无需手动输入，可新建文件夹
- **自动授权**：自动从页面内存、URL 参数、输入框提取提取码/stoken，多数情况无需手动输入
- 目标网盘自动重建目录链（先查重名再创建，中断重跑不产生重复文件夹）
- 转存任务轮询直至完成，单批失败不中断整体
- 批次实时状态、失败重试/拆半重试、结果 JSON 导出
- 纯逻辑自检：脚本加载时校验分批算法（叶子守恒/批次不超限/超大目录下钻）

## 原理

直接调用夸克网页端同源接口（`drive-pc.quark.cn`），与网页操作完全一致：

| 步骤 | 接口 |
|---|---|
| 获取访问凭证 | `POST /share/sharepage/token` |
| 扫描目录 | `GET /share/sharepage/detail`（分页 + total 对齐） |
| 列出目标网盘目录 | `GET /file/sort`（去重比对用） |
| 建目录 | `POST /file` |
| 转存 | `POST /share/sharepage/save` |
| 任务轮询 | `GET /task` |

## 注意

- 需先登录夸克网盘网页版（转存接口依赖登录态）
- 接口为网页端逆向所得，夸克改版可能导致失效
- 请求间有 350ms 限速，避免触发风控；大量文件时扫描/转存需要一定时间，请保持页面开启
- 去重比对会额外请求目标网盘目录列表，文件越多比对耗时越长，但能避免重复转存
